# 包仔 IP 圣经

## 形象

小笼包「包仔」：白色圆身、顶部褶子当发型、两团腮红、黑领结、两只小短脚，紧张时右颊挂一滴汤（不是汗，是汤）。yuru-chara 扁平厚描边、无阴影、马卡龙色。

- 立绘与骨架：`/Users/max/codebase/comedy/assets/char.png`、`rig.json`（眼睛/嘴坐标），由 `rig.py` 从概念图 `/Users/max/codebase/ComfyUI/output/ip/concepts/bao.png` 抠图 + 补绘生成。
- 舞台与道具：`/Users/max/codebase/ComfyUI/output/ip/props/` — `stage_vert.png`（砖墙开放麦）、`mic.png`、`ai_lead.png`（戴领结的显示器机器人 = AI 领导）。
- 气质参照吉伊卡哇/乌萨奇，但**必须是自创形象**，不得二创、不得直接使用他人角色。

## 性格与语气

- 俏皮、嘴硬、心软；用「汇报体」讲惨事（"今天就跟大家汇报一下，我是怎么一步一步被AI优化的"）。
- 把职场黑话按字面理解并当场拆穿（降本增效 = 降我；毕业 = 出殡；待定 = 已经定了，你还在）。
- 自嘲但不怨毒；每次泄气之后自己圆回来。
- 招牌动作：漏汤、被蒸、假装不紧张。

## 音色（不可随意更换）

Qwen3-TTS VoiceDesign 生成的 `v2_cheeky`（"清亮俏皮的少年音，语速偏快，尾音上扬，透着机灵和坏笑"），再用 Base 模型克隆锁定；参考音频 `/Users/max/codebase/tts/out/voices/v2_cheeky.wav`，参考文本固定。说话人 embedding 余弦相似度 0.992–0.994。

换音色 = 换 IP，必须先经用户同意。细节见 `qwen3-tts-voice` skill。

## 平台与规格

- 竖屏 1080×1920、30fps、AAC 192k、响度约 -15 LUFS、峰值 ≤ -0.8 dBTP。
- 字幕基线 `SUB_Y=1690`，安全宽度 `W-170`，最多 2 行；标题/章节标签在左上，灯牌在中上。
- 封面：1080×1920，红色横幅标题（88px）+ 深色胶囊副标题（40px），见 `puppet-talk-render`。
- 发布节奏：前 3 秒必须出现人设 + 冲突（EP04 冷开场 7 句完成）。

## 红线

- 不做二创、不用他人形象或声音。
- 不点名真实公司/真人开涮，不做地域、性别、疾病梗，不说脏话。
- 不假装是真人演出；AI 生成的观众笑声要在片尾或文案里说明是合成（若对外发布）。
- 本地服务只绑 `127.0.0.1`；不读取或外泄任何密钥；不做真实付费 API 调用。
