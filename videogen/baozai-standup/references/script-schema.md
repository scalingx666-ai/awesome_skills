# 台词脚本格式 `script_epNN.py`

文件只导出一个 `LINES` 列表，被 `gen_voice.py` 用 `importlib` 动态导入（`script_ep04.py` → `--ep 4`）。

```python
"""EP05 · 主题 —— 一句话说明。"""

LINES = [
    dict(id="01", text="大家好，我是包仔。一个包子。",
         pause_before=1.5, pause_after=0.35, punch=False, laugh=1),
    dict(id="02", text="对，就是那个一蒸就熟、一凉就硬、一捏就漏的包子。",
         pause_before=0.0, pause_after=0.55, punch=True, laugh=1),
    dict(id="08", text="我们公司买了个AI，说是降本增效。",
         pause_before=1.2, pause_after=0.25, punch=False, laugh=0,
         chapter="01 · 我的AI领导"),
    dict(id="30", text="包仔，早餐呢？",
         pause_before=0.8, pause_after=0.4, punch=False, laugh=0, who="ai"),
    dict(id="112", text="所以你们真正该怕的，是停电。",
         pause_before=0.0, pause_after=1.80, punch=True, laugh=3, applause=True),
]
```

## 字段

| 字段 | 必填 | 取值 | 作用 |
|------|------|------|------|
| `id` | 是 | 两位字符串 `"01"`…`"99"` | 决定 `audio/epNN/lines/{id}.wav`；超过 99 句要改成三位并同步改渲染读取逻辑 |
| `text` | 是 | ≤ 34 汉字 | 台词本体；字幕最多 2 行，超 40 字会挤成小字 |
| `pause_before` | 是 | 秒 | 上一句结束到本句开始的静音；同时是「上一句字幕消失 + 观众笑完」的余量 |
| `pause_after` | 是 | 秒 | 本句说完后的静音，笑点要留够 |
| `punch` | 是 | bool | 笑点：字幕变琥珀色、字号 60、角色小跳（11px + 3% 挤压） |
| `laugh` | 否 | 0–3 | 观众反应强度：0 无、1 轻笑、2 明显、3 大笑 |
| `applause` | 否 | bool | 叠加掌声（约 1.95s）；**末句必须为 True**，否则收尾反应被切 |
| `who` | 否 | `"bao"`（默认）/ `"ai"` | `"ai"` 走机器人变声 + 提示音 + 青光 + 青蓝字幕 |
| `chapter` | 否 | `"NN · 标题"` | 在该句前 1.25s 插全屏章卡，并在左上角常驻该标签直到下一幕 |

## 停顿参考值

| 场景 | `pause_before` | `pause_after` |
|------|----------------|---------------|
| 普通铺垫句 | 0.0 | 0.30–0.40 |
| 铺垫句后紧跟笑点 | 0.0 | 0.25–0.35 |
| 笑点句（laugh 1–2） | 0.0 | 0.55–0.95 |
| 大笑点（laugh 3） | 0.0 | 1.00–1.25 |
| 章卡首句 | ≥ 1.25 | 0.25–0.55 |
| AI 插话 | ≥ 0.7（提示音提前 0.45s） | 0.40–0.50 |
| 情绪落点（不笑的那句） | 0.0 | 1.20–1.60 |
| 末句 | 0.0 | 1.50–1.80 |

## 时长估算

实测语速 **5.4 汉字/秒**（EP04：2105 字 → 388s 语音 + 88s 停顿 = 476s ≈ 7:56）。

目标秒数 `T`：`字数 ≈ (T - 停顿总秒) × 5.4`。5 分钟专场 ≈ 1450 字 + 60s 停顿；8 分钟 ≈ 2100 字 + 88s。生成完以 `audio/epNN/timing.json` 的 `total` 为准，估算只用于写稿时控篇幅。

## 三幕模板（EP04 实测结构）

1. **冷开场 01–07**（7 句 / ~30s）：我是谁 + 世界观 + 本集命题，最后一句报幕（"今天就跟大家汇报一下，我是怎么一步一步被AI优化的"）。
2. **幕一 08–32**（职场）：章卡句 → 递进笑点 → 一次 AI 插话 → 幕尾掌声。
3. **幕二 33–64**（恋爱）：同构，但情绪更私人；中段插入「笑着笑着不笑了」的落点（61–62 句），立刻用 63–64 句圆回笑点。
4. **幕三 65–112**（自我/观点）：把前两幕的对象换成自己；AI 第二次插话（80）用来自嘲「被 KPI 管到讲多久」；101–107 给论点，108–112 收尾 + button 金句。

## 自检清单（交稿前）

- [ ] 总字数与目标时长一致（5.4 字/秒）
- [ ] 每句 ≤ 34 字，无连续 3 句不带 `punch` 且不带推进
- [ ] 每个笑点的包袱在句尾，不在句首
- [ ] 3 个章卡句 `pause_before >= 1.25`
- [ ] 至少 1 处 `who="ai"`，且下一句立刻回应它
- [ ] 至少 2 个前作 callback（见 `ip-bible.md` 系列日志）
- [ ] 1 处「不搞笑」的情绪落点 + 紧跟一个圆场
- [ ] 末句 `punch=True, laugh=3, applause=True`，且是一句能当标题的话
- [ ] `id` 连续、无重复、无跳号
- [ ] 改完脚本再启动配音（模块一旦导入就不会热更新）

## 常见错误

- 章卡句 `pause_before` 太小：上一句字幕（延后 0.45s 消失）还挂着，章卡就压上来。
- 笑点后 `pause_after` 太短：笑声被下一句压掉，听起来「观众很假」。
- 把 AI 台词写长：机器人插话 6–20 字最像系统提示，长了变声会糊。
- 一集里塞两个主题：专场可以三线合一，但必须同一内核（EP04 内核 = 「被优化的还是不是我」）。
- 结尾停在笑点：8 分钟片子结尾要停在「观点 + 掌声」，不是最后一个梗。
