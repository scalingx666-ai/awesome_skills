# 情侣日常档（EP06 起）格式与写法

一男一女两个包仔同框对话，3 分钟一集，无观众、无麦克风、无灯牌。节奏完全由剧本里的
`pause_*` 字段决定（TTS 逐句合成，画面是 2D 木偶），所以**写剧本等于同时写剪辑表**。

## 两个角色

- **包仔**（`who="bao"`）：白色小笼包，黑领结，一紧张右颊漏汤。俏皮、嘴硬、心软、爱狡辩，
  擅长把责任说成科学。音色 = 清亮俏皮少年音，语速 ≈6.0 字/秒。
- **小满**（`who="girl"`）：同款小笼包，齐刘海短发、睫毛、头顶褶子扎成小揪揪配两片绿叶、
  红蝴蝶结，**她也会漏汤**（这是两人共同的软肋，也是母题）。清亮、伶利、嫌弃但宠，
  咬字快、爱反问、算账清楚。音色 = 软糯嗲的高音调女声（比包仔高约 1.3 倍），语速 ≈5.2 字/秒。

两人都不许被写成工具人：她的台词行数 ≥ 全集 40%，且至少两次是她赢。
「漏汤」只能当情绪证据用（谁先漏汤谁先认），不要重复解释设定。

## 三幕结构（60–64 句）

1. **钩子（1–8 句，前 14 秒）**：第一句话必须直接抛冲突或悬念。禁止"今天我们来聊聊"式开场。
2. **升级拉锯（9–40 句）**：每 4–6 句一个笑点，双方各让一步又各翻一次车。
3. **反转 + 甜（41–末尾）**：反转放在全集 70–80% 处，必须推翻观众前面相信的前提
   （"原来她早就知道""原来单子是她点的"）。落点固定母题：**倒数第二句很甜，最后一句很现实**
   （例：`我怕我沾水。你沾，我心疼。` / `碗你洗。`），最后一行 `pause_after=0.9`。

## 数据格式

```python
"""EPNN · 包仔情侣日常《标题》— 一句话主题。

（docstring 写清三幕各在哪几句、反转是什么、回收了哪个旧梗）
"""

SCENE = dict(title="标题", room="living", cover=("封面大字", "封面小字"))

LINES = [
    dict(id="01", text="包仔，今天几号呀？", who="girl",
         pause_before=0.5, pause_after=0.3, punch=False),
    ...
]
```

`SCENE.room` 只有 `"living"`（客厅：薄荷绿墙 + 沙发 + 茶几）和 `"kitchen"`（厨房）两档，
`render.py` 的 `couple_episode()` 靠它选舞台；`cover` 是封面的红横幅 + 深色胶囊两行字。

## 硬约束（不达标就出不了 3 分钟，或不好笑）

| 项 | 要求 |
|----|------|
| 行数 | 60–64 |
| 全集字数 | 860–920（≈5.6 字/秒 ⇒ 台词 155–165s，加停顿正好 3 分钟） |
| 停顿之和 | `sum(pause_before + pause_after)` 落在 28–36 秒；单值：接话 0.15–0.30，转折 0.5–0.90，最大不超过 1.2 |
| 单句长度 | ≤ 28 字（含标点），不换行、不嵌套引号、不用 emoji |
| `who` | 只有 `"bao"` / `"girl"`，不要旁白、观众、AI、妈妈（需要别人说话时转述） |
| `punch=True` | 全集 10–14 个，两人各占约一半，相邻两个至少隔 3 行（这是角色跳一下的爆点标记） |
| 禁用字段 | `laugh` / `applause` / `chapter` / `hook`（情侣档没有观众，写了也没人接） |
| 语言 | 中文口语，能直接读出来；无品牌名、无脏话、无性暗示、无地域/性别/疾病梗、无网络烂梗（yyds、绝绝子之类） |
| callback | 至少回收 2 个旧梗（漏汤、被蒸、褶子、馅儿、一屉、蒸笼、"碗你洗"），再种 1 个新梗 |
